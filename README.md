# Proyecto SO1 – Grupo 9
Este repositorio cuenta con el proceso de la construcción del sistema LFS  y del desarrollo de la SHELL.
## Contenido del repositorio
- Sistema LFS con systemd completamente construido y operativo
- Shell personalizada integrada al sistema
- Evidencias del proceso de ambos
## Estructura del repositorio
-	`docs/`
Documentación técnica e informes relacionados con la shell y el sistema.
- `evidencias/`
Capturas y registros del avance del proyecto, organizados por capítulos del manual de LFS.
- `shell/`
Código fuente de la shell personalizada desarrollada para el proyecto.
- `diario.md`
Registro cronológico de las sesiones de trabajo, decisiones tomadas y avances durante la construcción del sistema LFS.
