# Proyecto SO1 – Grupo 9
Este repositorio cuenta con el proceso de la construcción del sistema LFS  y del desarrollo de una shell personalizada.
## Contenido del repositorio
- Sistema LFS con systemd completamente construido y operativo
- Shell personalizada integrada al sistema
- Evidencias del proceso de ambos
## Estructura del repositorio
-	`docs/`
Contiene la documentación técnica del proyecto, incluyendo informes, explicaciones del proceso de construcción del sistema LFS y el funcionamiento de la shell.
- `src/`
Contiene el código fuente principal del proyecto.
- `test/`
Contiene pruebas y archivos de verificación para comprobar que el programa funciona correctamente.

## Instalación y configuración inicial: Pasos previos a la utilización
Antes de ejecutar la shell, es necesario crear el directorio destinado al almacenamiento de los logs del sistema.
Ejecutar los siguientes comandos con permisos de superusuario:
- sudo mkdir /var/log/shell
- sudo chmod 777 /var/log/shell
